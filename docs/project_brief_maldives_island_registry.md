# Project PRD: Maldives Island Registry & Coalition for Open Governance Portal

## 1. Project Overview
The **Maldives Island Registry** is a high-fidelity geospatial platform serving as the definitive public portal for exploring the islands of the Maldives. Built and governed by the **Coalition for Open Governance**, the platform combines official geospatial data with historical, environmental, and administrative information to empower citizens, researchers, and policymakers through data transparency.

## 2. Target Audience
*   **General Public:** Citizens seeking information about their home islands or travel destinations.
*   **Researchers & Journalists:** Users requiring authoritative, downloadable datasets for analysis and reporting.
*   **Government Agencies:** Stakeholders needing a unified view of national geospatial assets.
*   **Environmental Organizations:** Groups monitoring protected areas, coral health, and climate indicators.

## 3. Core Features & Screen List

### 3.1 Homepage
*   **Hero Section:** Interactive map preview with a prominent search bar (search by island, atoll, or resort).
*   **Quick Stats:** Real-time counters for total islands, inhabited islands, resort islands, and protected areas.
*   **Mission Module:** Dedicated section for the Coalition for Open Governance mission and leadership vision.

### 3.2 Map Explorer
*   **Full-Screen GIS Interface:** Advanced map viewer with layer controls (topographic, bathymetric, cadastral).
*   **Filtering:** Ability to filter by atoll, island type, and administrative status.
*   **Tools:** Hover information cards, coordinate displays, and measurement tools.

### 3.3 Island Profile
*   **Geospatial Live View:** High-resolution map and photo gallery for specific islands.
*   **Information Tabs:** Overview (administrative), Geography (area/elevation), Environment (wetlands/biodiversity), and Infrastructure.
*   **Download Portal:** Direct links to GeoJSON, CSV, and PDF summaries.

### 3.4 Data Downloads Catalog
*   **Inventory Management:** Searchable list of all public datasets (Atoll Boundaries, Coral Health, Population Census).
*   **Bulk Actions:** One-click downloads and API documentation access.
*   **Data Integrity:** Verification badges showing the "Verified" or "Pending" status of official records.

### 3.5 Environmental Dashboard
*   **Health Indices:** Visual charts for coral reef health, average salinity, and sea temperatures.
*   **Growth Tracking:** Marine Protected Area (MPA) progress against national targets.
*   **Regional Snapshots:** Tabular view of key habitat statuses across different atolls.

### 3.6 Admin Dashboard
*   **Data Moderation:** Interface for authenticated editors to approve submissions and sync databases.
*   **Audit History:** Detailed log of all metadata refinements and satellite acquisitions.
*   **Satellite Acquisition:** Preview and metadata for recent Sentinel-2 imagery syncs.

## 4. Design & Branding
*   **Design System:** *Atoll Geometric* (Modern, clean, data-rich).
*   **Color Palette:** Ocean Deep (#003366), Reef Turquoise, Island Green, and White Sand Neutrals.
*   **Typography:** Inter (Sans-serif) for high readability across data-dense tables.
*   **Institutional Framing:** Consistent global footer featuring the Coalition logo, mission statement, and the leadership quote from Ahmed Afrah Ismail.

## 5. Mission Statement
> "Open Data redistributes power that has been consolidated by a few. Those who benefit from secrecy will fight it. They will lose. Open Data is inevitable, question is will you proactively embrace it?" — **Ahmed Afrah Ismail**, Coalition for Open Governance.

## 6. Development Philosophy
*   **Open Source Roots:** "Built with public assets, by the public for the public."
*   **Transparency First:** Every data point includes source attribution and verification dates.
*   **Mobile-First:** Fully responsive layouts ensuring accessibility on desktop and mobile devices.
